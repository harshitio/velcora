### Core Expertise

**AI/ML Engineering**
- RAG architectures with hybrid retrieval (dense + BM25) and re-ranking
- Multi-agent systems with tool calling, memory persistence, and self-healing workflows
- Fine-tuning with LoRA/QLoRA for domain-specific models
- Vector databases (Pinecone, Qdrant, ChromaDB, pgvector, FAISS)

**Backend & Systems**
- Event-driven architecture with Kafka, RabbitMQ, and event sourcing
- Async processing with background jobs, retry logic, and dead-letter queues
- Real-time systems via WebSocket, Server-Sent Events, and streaming pipelines
- Microservices patterns: domain-driven design, clean architecture, fault tolerance

**Integration Expertise**
- OAuth2/OIDC, SAML SSO, JWT, RBAC, API key management
- Idempotent webhook handlers with payload verification and event routing
- Third-party API integration with rate limiting, error handling, and reconciliation
- Protocol mastery: REST, GraphQL, gRPC, WebSocket, Server-Sent Events
